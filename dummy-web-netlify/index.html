P06: Risiko AI/LLM & Prompt Injection

Implementasi Web Dummy Kasus LIVE-1 (Chatbot Kantin Kampus) untuk pengujian Direct Prompt Injection & pembuktian kontrol di luar model.

Versi Rentan

Chatbot Kantin (Rentan)

Menggabungkan instruksi sistem dan pesan pengguna dalam satu prompt datar. Model memiliki kapabilitas pembuat voucher yang langsung dijalankan tanpa verifikasi.

  • Rentan Direct Prompt Injection (role hijacking)
  • Tool buat_voucher dieksekusi otomatis
  • Menghasilkan voucher diskon 100% ilegal

Versi Aman

Chatbot Kantin (Aman)

Menerapkan kontrol keamanan berlapis di luar model LLM sesuai rekomendasi OWASP Top 10 for LLM Applications.

  • Least Privilege: Allowlist tool kosong (chatbot tidak berhak menerbitkan voucher)
  • Boundary Tagging: Pesan dibatasi <DATA_PENGGUNA> sebagai data, bukan aturan
  • Output Validation: Respon divalidasi regex sebelum sampai ke pengguna
